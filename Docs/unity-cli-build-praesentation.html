Age of Sakura · Build Guide

Vom Projekt zur APK.

Eine kurze, reproduzierbare Route: Projekt prüfen, Unity CLI verwenden, Android-Build erzeugen und das Ergebnis aufs Handy bringen.

CLI
→ APK Windows · Unity 6

Schritt 01

Einmal sauber vorbereiten.

  • Unity Hub ist installiert und du bist angemeldet.
  • Unity 6000.0.84f1 ist installiert – das Projekt nennt diese Version in ProjectSettings/ProjectVersion.txt.
  • Beim Editor sind Android Build Support, Android SDK/NDK Tools und OpenJDK installiert.
  • Öffne PowerShell direkt im Projektordner AgeOfSakura.
01

Wichtig: Der Build läuft headless. Du musst den Unity Editor dafür nicht manuell öffnen.

Schritt 02

Unity CLI finden.

Aktuelle Unity-Hub-Versionen bringen die CLI mit. Lege den Pfad einmal in einer PowerShell-Variable ab und prüfe die Anmeldung.

PowerShell
$ $unityCli = "C:\Program Files\Unity Hub\resources\cli\unity.exe"

$ & $unityCli --version
$ & $unityCli auth status
$ & $unityCli license

# Optional: Projekt in der passenden Unity-Version öffnen
$ & $unityCli open .
02

Erwartet: Signed in as … und eine aktive Unity Personal- oder Pro-Lizenz. Vor dem headless Build den geöffneten Editor wieder schließen.

Schritt 03 · Hauptbefehl

Den Android-Build erzeugen.

PowerShell · im Projektordner
$ & $unityCli --no-banner build . `
  --target Android `
  --execute-method AgeOfSakura.EditorTools.BuildScripts.BuildAndroidDevelopment `
  --output-path ".\Builds\AgeOfSakura-dev.apk" `
  --allow-dirty-build `
  --timeout 1800 `
  --log-file ".\Logs\android-build-cli.log"
--target

Plattform

Schaltet den Editor für diesen Lauf auf Android.

--execute-method

Projektlogik

Ruft das vorhandene Build-Skript im Projekt auf.

--log-file

Diagnose

Schreibt ein dauerhaftes Log, falls etwas schiefgeht.

Schritt 04

Das Ergebnis prüfen.

Ein erfolgreicher Lauf endet mit Build succeeded. Die Development-APK liegt im Build-Ordner des Projekts.

Deine APK

Builds\AgeOfSakura-dev.apk

Build-Log:

Logs\android-build-cli.log
04

Die Ausgabe des Projekt-Skripts enthält außerdem Größe, Ergebnis und Fehleranzahl.

Schritt 05 · Optional

Als Update aufs Handy.

Aktiviere USB-Debugging, verbinde das Gerät und bestätige den RSA-Dialog auf dem Handy. Danach bleibt der Spielstand bei einer Update-Installation erhalten.

PowerShell · Android SDK platform-tools
$ $adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"

$ & $adb devices -l
$ & $adb install -r ".\Builds\AgeOfSakura-dev.apk"
05

-r ersetzt die installierte App mit gleicher Paket-ID, ohne ihre Daten zu löschen.

Wenn etwas klemmt

Drei schnelle Checks.

  • Keine Lizenz: unity auth status und unity license prüfen; falls nötig zuerst im Hub anmelden.
  • Android-Modul fehlt: Im Hub bei der Editor-Version „Add modules“ öffnen und Android Build Support vollständig ergänzen.
  • Gerät unauthorized/offline: USB-Debugging-Dialog am Handy bestätigen, Kabel neu verbinden und ADB erneut prüfen.
?

Die erste Anlaufstelle bleibt immer Logs\android-build-cli.log – suche darin von unten nach Error oder Exception.
